# MoreLink

Link de texto que leva para a página completa de um resumo, com uma seta.

## Quando usar
Na ação de um SectionTitle ("Ver tudo") ou no pé de um card de resumo ("Resultado completo").

## O que você fornece
- `href`: destino.
- `children`: o texto, curto. A seta → é adicionada pelo componente e é decorativa.

## Faça
- 14px bold em `text-2`, `text` no hover.
