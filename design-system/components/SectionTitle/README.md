# SectionTitle

Título de seção dentro de uma página, com ação opcional à direita.

## Quando usar
Para abrir cada bloco de conteúdo (tabela, gráfico, grade de cards), com `space-10` acima e `space-3` abaixo.

## O que você fornece
- `children`: o título. Em gráficos, use o padrão "Evolução do campeonato | Pontos", com a parte depois da barra em `muted`.
- `action` (opcional): normalmente um MoreLink ("Ver tudo").
