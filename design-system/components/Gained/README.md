# Gained

Posições ganhas ou perdidas entre o grid e a chegada, com seta e cor.

## O que você fornece
- `value`: grid menos posição final. Positivo ganhou, negativo perdeu, zero não mudou.

## Faça
- ▲ em `gain` e ▼ em `loss`, em bold; zero vira um traço em `muted`. O `aria-label` diz "Ganhou 3 posições".
- A seta nunca sai: a cor sozinha não basta.
